# MacroForge

Keyboard and mouse macros for Windows 10 and 11, set up without code: recoil compensation with a
preset per gun, automatic gun detection, a DMR rapid-fire mode, sequences, text typing, profiles
that switch with the game, and an on-screen overlay.

## Download

1. Download **MacroForge.exe** from the [latest release](https://github.com/liam070507-jpg/MacroForge/releases/latest).
2. Put it in a folder of your own, for example `Documents\MacroForge` (not Program Files, so it can
   update itself).
3. Double-click it. MacroForge runs in the tray (bottom right of the taskbar); closing its window
   keeps it running.

The first time, Windows may show **"Windows protected your PC"** because MacroForge isn't
code-signed: click **More info**, then **Run anyway**. On PCs with **Smart App Control** turned on,
Windows blocks it.

## Updates

MacroForge checks here for a new version when it starts and asks before installing it. You can also
check yourself: **Settings → Updates → Check for updates**. Your profiles and settings are kept;
they live in `%AppData%\MacroForge`.

## Fair play

MacroForge only uses normal Windows input functions and never reads or changes a game's memory.
Many online games still forbid macros, recoil compensation in particular, and anti-cheat systems
can detect them. Check the rules of the games you play; you use it at your own risk.
